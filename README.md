# Festa de Multiplicação — Central de Posts

Dashboard operacional em tempo real para a **Festa de Multiplicação**: uma central de posts onde equipes distribuídas movem demandas de conteúdo por uma esteira de produção, com visibilidade controlada por conta, cronograma do evento, painel de KPIs e relógio/cronômetro do evento.
